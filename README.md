# 🦸 Marvel Quiz

Ce projet a été réalisé en suivant un cours sur Udemy, et il m'a permis d'approfondir mes compétences en React et d'explorer l'intégration d'une API externe. Le site est un quiz interactif basé sur l'univers Marvel.

## 🌟 Fonctionnalités
- 🔒 Connexion avec Firebase : Les utilisateurs doivent se connecter pour accéder au quiz.
- ❓ Quiz Marvel : Trois niveaux de difficulté avec des questions variées sur l'univers Marvel.
- 📜 Résultats détaillés : À la fin du quiz, les utilisateurs peuvent consulter les bonnes réponses et obtenir des informations sur les personnages des questions via l'API Marvel.
  
## 💻 Technologies utilisées
- React : Pour le développement de l'interface utilisateur.
- Firebase : Gestion de l'authentification et de la base de données.
- API Marvel : Récupération des informations sur les personnages et les univers Marvel.
